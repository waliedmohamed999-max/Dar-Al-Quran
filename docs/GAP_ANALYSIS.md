# تحليل الفجوات: المرحلة الثالثة (V3)

> هذا تحليل المرحلة الثالثة كما كان. أغلقت مرحلة لاحقة كثيراً من بنوده: انظر الحالة الحالية في [الميزات](release/FEATURES.md).

فحصت هذه المرحلة ما بني سابقاً، وأعادت استخدامه بدل تكراره. «مكتمل» يعني وجود قاعدة البيانات والخادم والواجهة والاختبار معاً.

## ما أعيد استخدامه دون جداول جديدة

| المطلوب | الموجود المعاد استخدامه |
|---|---|
| Questions وQuestionBanks | `questions`، مع أنواع جديدة ووسوم |
| ExamAttempts وExamAnswers | `assessment_attempts` و`assessment_answers`، مع رقم محاولة ووقت انتهاء |
| ExamReviews | تصحيح `gradeAttempt` والاعتراضات `exam_appeals` |
| LearningPlans وDailyAssignments | `learning_plans` و`daily_tasks` |
| MemorizationRecords وRevisionSchedules | `memorization_records` و`revision_records` |
| RecitationSubmissions وTeacherAssessments | `recitation_submissions` و`teacher_reviews` |
| TajweedLessons | `tajweed_rules` |
| ContentReviewRecords | حقول المراجعة مع `audit_logs` |
| QuranStudySessions | `ayah_progress` و`tafsir_progress` و`lesson_progress` |

## حالة كل وحدة

| الوحدة | المكتمل | الناقص |
|---|---|---|
| 1. الأذكار | البطاقات، العداد، النسخ والمشاركة، المفضلة، محرك الجدولة بالمنطقة الزمنية، مواقيت الصلاة، عدم الإزعاج، الفاصل، السجل، الإدارة والمراجعة | الصوت: لا مصدر مرخص. الشرح والتخريج: فارغان حتى يضيفهما مختص. Web Push لم يجرب على متصفح حقيقي |
| 2. الحديث | المكتبة، صفحة الحديث، التدريبات، التسميع، تقييم المعلم، الجدولة، مسار الأربعين، إدارة التوثيق | الأحاديث بلا درجة ولا شرح حتى تضاف من مرجع. لا اختبار نهائي مرتبط تلقائياً، والشهادة عبر مسار الشهادات العام. البحث بالموضوع غير منفذ. مسار واحد فقط |
| 3. تحديد المستوى | المراحل الخمس، الحفظ التلقائي، الأسئلة، تحقق الحفظ من النص المخزن، ملف المهارات السبع، التوصية، اعتماد المعلم، الطباعة | التعليمات الصوتية والاختبار التجريبي غير منفذين. بنك الأسئلة في الإنتاج تكتبه الدار |
| 4. المسابقات | البوابة، الأنواع، التسجيل، المحرك، الحفظ والاستئناف، العشوائية، المحاولات، سجل الأحداث، الاعتراض، لوحة الترتيب الاختيارية | تحكيم شفهي مباشر: يسجل كسؤال ويقيم يدوياً، بلا جلسة تحكيم. الشهادة تطلب بعد النتيجة يدوياً |
| 5. المتابعة اليومية | رحلتي، حالة كل آية، الخريطة، محرك أولويات المراجعة، سجل التسميع، التقارير | لا درجة صعوبة مستقلة للمقطع؛ يستعاض بمعامل السهولة ونتائج المراجعة |
| 6. المصحف | الأوضاع الستة، نطاق وتكرار، إخفاء تدريجي، ترتيب، ملاحظات، أحكام الكلمة، الانتقال، الأحزاب، وضع التركيز | توزيع أسطر مطابق للمطبوع، تمييز الكلمة أثناء التلاوة، أمثلة صوتية منفصلة لكل حكم، معاني المفردات وأسباب النزول |
| 7. أكاديمية التجويد | المستويات، الدرس، الأمثلة، السؤال، النتيجة، ملاحظة المعلم، الربط بالكلمة | شرح مرئي، صوت لكل مثال، واجب مرتبط بالدرس (يعين بمهمة عامة)، ومحتوى المستوى الرابع |
| 8. التفسير | دراسة السورة، التفسير بالآية، المقارنة، التقدم، الربط بالمصحف والمساعد | الموضوعات والمفردات وأسباب النزول والفوائد: لا مصدر مرخص. اختبارات الفهم تضاف عبر بنك الأسئلة |
| 9. التوحيد | التدفق من التسجيل حتى التقرير مختبر كاملاً في اختبار واحد، وكلها على ملف الطالب نفسه | إدارة المسارات: قائمة ثابتة في الكود |
| 10. الجودة | RLS للجداول الجديدة، اختبارات التوقيت الصيفي والصلاحيات والتسجيلات | Chromium فقط، لا Firefox ولا Safari |

## قرارات لها أثر عليك

- **لا أكتب نصوصاً دينية من الذاكرة.** لذلك تبقى حقول الدرجة والشرح والمفردات فارغة بتصريح واضح للمستخدم.
- **لا ترتيب بين الطلاب افتراضياً ولا قياس للأذكار.** العداد لا يخزن، ولوحة الترتيب اختيارية وبموافقة وتستثني القاصرين.
- **التقييم الآلي مؤشر فقط.** الإتقان وملف المهارات لا يكتبهما إلا المعلم.
- **لا كشف غش.** تسجل الأحداث فقط، دون ادعاء اكتشاف الغش.
