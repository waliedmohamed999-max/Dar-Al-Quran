# المعمارية

Modular Monolith: منطق الأعمال في `src/modules/*`، والواجهات في `src/app`، والبنية المشتركة في `src/lib`.

| الوحدة | المسؤولية |
|---|---|
| `quran` | النص، البحث، المحاذاة، محولات المزودين (Adapters) |
| `learning` | الخطط، المخطط اليومي، المراجعة المتباعدة، التسميع |
| `halaqat` | الحلقات، الانتساب، الحضور، الفصول المباشرة |
| `assessments` | بنك الأسئلة، الاختبارات، الشهادات |
| `ai` | الاسترجاع، فحص الإجابات، المزود |
| `site`, `cms` | البرامج، تحديد المستوى، البحث، النشرة، المحتوى |
| `people`, `notifications`, `reports` | الحسابات، الإشعارات، التقارير والتصدير |

## قرارات مبررة

- **دار واحدة:** أزيلت الفروع بالترحيل `20261031000300`. نقل اسم الفرع إلى مكان الحلقة إن كان فارغاً، وأصبح أي دور كان مقيداً بفرع دوراً على مستوى الدار.
- **اتصالان بقاعدة البيانات:** `withActor` يعمل بالدور المقيد `dar_app` وتطبق عليه RLS. أما `systemDb` فهو لدور المالك ويقتصر على المصادقة والمحتوى العام والعمليات الخلفية وكتابات يتحقق الخادم قبلها من الصلاحية.
- **طابور في PostgreSQL بدل Redis:** جدول `jobs` مع `FOR UPDATE SKIP LOCKED`. يكفي الحجم المتوقع، ويقلل الخدمات، ويسهل مراقبته.
- **حد المعدل في PostgreSQL:** ليعمل عبر عدة نسخ من التطبيق دون خدمة إضافية.
- **مصحف نصي مرن:** ترقيم صفحات مصحف المدينة محفوظ، لكن توزيع الأسطر غير مطابق للمطبوع.
- **الصوت ملف لكل آية:** انتهاء الملف يحدد نهاية الآية بدقة دون بيانات توقيت. جدول `audio_timings` ومحول التوقيت موجودان، ولا تستخدمهما الواجهة بعد.
- **الاسترجاع المعجمي بدل التضمينات:** قاعدة المعرفة صغيرة ومراجعة، والبحث المعجمي شفاف، ويتفادى قيود تخزين محتوى المزودين.
- **API جدول واحد:** `src/modules/api/endpoints.ts`، ومنه يولد `docs/API.md`.
