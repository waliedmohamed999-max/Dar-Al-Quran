# خطة اختبار قبول المستخدم (UAT)

**لمن:** فريق الدار. نفذها على بيئة staging بأشخاص حقيقيين وأجهزتهم، ولا تستخدم مفاتيح الإنتاج. سجل لكل بند: نجح أو فشل، والجهاز والمتصفح والملاحظة.

**المشاركون المقترحون:** مدير، ومشرف علمي، معلمان، 5 طلاب بينهم قاصر، وولي أمر.

**معيار القبول:** نجاح كل بنود الأولوية 1، و90% من الأولوية 2، وعدم وجود خطأ يمس النص القرآني أو خصوصية طالب.

|---|---|---|---|

| S5 | الاستماع، وتكرار الآية، وتمييز الكلمة | التمييز يوافق التلاوة قبولاً | 1 |
| S6 | أوضاع المصحف الستة على هاتف | النص سليم، ولا تمرير أفقي | 1 |

## الرحلة الكاملة (ينفذها الجميع معاً)

تسجيل طالب ← تأكيد البريد ← الاختبار التجريبي ← تحديد المستوى ← قرار المعلم ← خطة ← ورد يومي ← تسجيل تسميع ← تقييم المعلم ← خريطة الحفظ ← مراجعة ← تسجيل في مسابقة أو اختبار ← تحكيم أو تصحيح ← اعتماد النتيجة ← طلب شهادة ← اعتمادها من شخص آخر ← التحقق العام منها ← تقرير ولي الأمر.
