# خطة الاختبار اليدوي: الصوت والفيديو

**لمن:** فريق اختبار الدار. **لا تغني المحاكاة عن هذه الخطة.** نفذها على staging بأشخاص حقيقيين، ولا تستخدم تسجيلات طلاب حقيقيين دون موافقة.

**الحالة الحالية لكل البنود: لم ينفذ.** الأجهزة الدنيا: آيفون Safari، أندرويد Chrome، حاسوب Chrome، حاسوب Firefox.

**المسؤول المقترح:** منسق UAT، ومعلم، وطالبان (أحدهما قاصر بموافقة وليه)، ومسؤول تقني.

سجل لكل حالة: ناجح أو فاشل، والجهاز والمتصفح والشبكة، ولقطة عند الفشل.
