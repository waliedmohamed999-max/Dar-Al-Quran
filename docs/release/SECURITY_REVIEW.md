# مراجعة الأمان

**لمن:** المسؤول التقني وجهة اختبار الاختراق. مراجعة شفرة واختبارات آلية، **وليست اختبار اختراق**. راجع أيضاً [سجل الثغرات](VULNERABILITIES.md).

## حدود معروفة

- لا اختبار حمل، ولا اختبار اختراق.
- سياسة كلمات المرور بسيطة، والمصادقة الثنائية اختيارية لغير المديرين (ومنهم المشرف والمعلم).
- الطالب القاصر يدخل بكلمة مرور فقط.
- لا تكامل Sentry، فالتنبيه من لوحة الإدارة فقط.

## نطاق اختبار الاختراق المستقل

**الهدف:** بيئة staging تطابق الإنتاج، ببيانات وهمية. لا يختبر الإنتاج بعد نشر بيانات حقيقية دون خطة.

**الحسابات المطلوبة:** مدير عام، ومدير، ومشرف، ومعلمان بحلقتين مختلفتين، وطالبان، وطالب قاصر، وولي أمر، وزائر.

| الأولوية | المجال | أسئلة محددة |
|---|---|---|
| حرج | IDOR و RLS | هل يصل معلم أو ولي أمر أو طالب إلى سجل أو تسجيل غيره، عبر الـ 143 مسار API وصفحات `/reports/[id]` و`/teacher/students/[id]`؟ |
| حرج | القاصرون | هل تتسرب أسماء أو تسجيلات عبر النتائج والمسابقات والتحقق من الشهادات؟ |
| حرج | المصادقة | تجاوز MFA، إساءة رموز الاسترداد، تثبيت الجلسة، الاستعادة، وتعداد الحسابات |
| عال | سلامة المحتوى | هل يمكن نشر غير المعتمد، أو تعديل نص القرآن أو الاعتماد دون صلاحية؟ |
| عال | الرفع والتخزين | ملفات متنكرة، تجاوز الحجم، إعادة استخدام الروابط الموقعة، والوصول المباشر للحاوية |
| عال | المعلم الذكي | حقن التعليمات، وتسريب بيانات الطلاب، والالتفاف على الفتوى |
| عال | المنطق | الشهادات والنتائج والاعتراضات والتحكيم وتزوير الدرجات |
| متوسط | CSRF و XSS | تجاوز Origin، وحقن المحتوى المعقم، وCSP |
| متوسط | إساءة الخدمة | حدود المعدل مع الوكيل، والبحث، والتصدير |
| متوسط | الإعدادات | الرؤوس، والأسرار، و`/api/health`، والحاويات |

**خارج النطاق دون إذن:** مزودو الخدمات الخارجيون، والهندسة الاجتماعية. **المخرجات:** تقرير بالشدة وخطوات الإعادة، وإعادة فحص بعد الإصلاح.
