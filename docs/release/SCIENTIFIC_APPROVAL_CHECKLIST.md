# قائمة الاعتماد العلمي

**لمن:** المشرف العلمي للدار. **الأداة:** [لوحة المراجعة](../../src/app/[locale]/(app)/admin/scholarly/page.tsx) على `/admin/scholarly`: تعرض لكل مادة المصدر والترخيص والمراجع المسؤول والنتيجة وسبب الرفض وسجل التعديل وتاريخ الاعتماد.

**الحالة: لم يعتمد أي محتوى بقرار بشري.** الاعتمادات الموجودة في قواعد التطوير تجريبية (`demo-seed`)، ولا تحسب في الإنتاج، وهذا مختبر بخادم يعمل كإنتاج.

## قواعد مفروضة في الخادم (مختبرة)

- غير المعتمد لا يظهر في الصفحات ولا API ولا البحث ولا خريطة الموقع.
- أي تعديل يعيد المادة إلى الانتظار ويخفيها فوراً.
- الرفض لا يقبل دون سبب، ويحفظ كل قرار مع بصمة النص.
- لا يعدل النظام النص القرآني، ولا يعتمد شيئاً آلياً.
