# فروق النص القرآني بانتظار مراجعة مختص

مقارنة آلية لهيكل الحروف، بعد حذف التشكيل، بين المصدرين لكل الآيات (6236). وجدت 5 مواضع. قد يكون الفرق في طريقة الكتابة بين المصدرين لا في القراءة، **والفصل فيه للمختص بالرسم والضبط لا للنظام**.

- لم يعدل أي نص آلياً، والمنصة تعرض نص Tanzil كما هو، ويفشل `npm run quran:verify` عند أي تغيير.
- لا تدل هذه القائمة على سلامة بقية الآيات من حيث التشكيل: المقارنة على الحروف فقط.
- المطلوب: مقابلة كل موضع بالمصحف المطبوع المعتمد، ثم تسجيل القرار هنا.

- **المصدر المستقل (Quran.com uthmani):** فَمَنۢ بَدَّلَهُۥ بَعْدَ مَا سَمِعَهُۥ فَإِنَّمَآ إِثْمُهُۥ عَلَى ٱلَّذِينَ يُبَدِّلُونَهُۥٓ ۚ إِنَّ ٱللَّهَ سَمِيعٌ عَلِيمٌ
