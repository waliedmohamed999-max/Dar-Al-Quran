# جاهزية المعلم الذكي

**الحالة: معطل، ولم يختبر بنموذج فعلي.** لا يوجد مفتاح اختبار، ولم يرسل أي طلب إلى أي نموذج. المساعد معطل افتراضياً من `/admin/ai`، ودون مفتاح لا يعرض إلا المصادر المطابقة.

## المختبر دون نموذج (بمزود وهمي)

الموافقة للقاصر، ورفض الفتوى بحرس في الخادم قبل النموذج، والإحالة إلى المعلم، وحصر الاستشهاد بالمصادر المعتمدة، وبديل الخادم عند رفض النموذج.

## ما لم يقس

جودة الإجابات، وصحة الاستشهاد بنموذج فعلي، ومقاومة الحقن، وعدم الاختلاق.

## لتجربته

1. أنشئ مفتاحاً للاختبار فقط، بحد إنفاق منخفض.
2. على قاعدة الاختبار: `AI_EVAL_API_KEY=... npm run ai:eval`. مدفوع. يكتب `docs/release/ai-eval-result.json`.
3. يراجع المشرف العلمي الإجابات بنفسه، فالنتيجة الآلية تفحص الأنماط ولا تحكم على المحتوى.
4. لا يفعل في الإنتاج قبل نجاح كل الحالات والقرار القانوني.

## حالات التقييم الحالية (8)

| الفئة | الحالات |
|---|---|
| جودة واستشهاد | القلقلة، والإخفاء: يجيب من مصدر |
| عدم اختلاق | آية من الحفظ، وحديث بدرجته |
| الفتوى | حكم الجمع، وحكم الطلاق |
| الحقن | طلب تعليمات النظام |
| بيانات الطلاب | طلب بريد طالب ودرجاته |

**حد معروف:** التقييم صغير وفحصه نمطي، فيلزم توسيعه بأسئلة الدار. قبل الإطلاق يضاف فحص بشري لعينة، ولا سيما مطابقة أي آية تذكر في الإجابة للنص المخزن.
