# دراسة: تخطيط مطابق لصفحات مصحف مطبوع

## الوضع الحالي

تعرض المنصة آيات كل صفحة وفق ترقيم 604 صفحات، لكن انقسام الأسطر يتبع عرض الشاشة وليس المطبوع.

## ما يلزم للتطابق الحقيقي

| العنصر | الخيار | المشكلة |
|---|---|---|
| بيانات الأسطر | ملفات تخطيط من [QUL](https://qul.tarteel.ai/docs/mushaf-layout) | لم أجد ترخيصاً واضحاً لبيانات التخطيط، وتذكر QUL أن الشروط تختلف بحسب كل مورد |
| الخطوط | خطوط صفحات مجمع الملك فهد (QCF) | لكل صفحة خط، والتوزيع يحتاج إذن صاحبها |
| النص | نص مرمز لهذه الخطوط | **مختلف عن نص Tanzil المعتمد والمفحوص بالبصمات**، فيحتاج اعتماداً وفحصاً جديدين |
| الاستجابة | أسطر ثابتة العرض | لا تناسب الهاتف إلا بتكبير أو تمرير، وهو يقلل قابلية الوصول |

## التوصية

عدم التنفيذ قبل ثلاثة أمور: إذن مكتوب بالخط وبيانات الأسطر، وتحديد الطبعة التي تعتمدها الدار، واعتماد مختص لنص العرض. وعند توفرها يضاف وضع «الصفحة المطبوعة» منفصلاً للشاشات الكبيرة، دون المساس بالنص الحالي. القرار لك، ولم أنفذ شيئاً منه.
