## يوم النشر

- [ ] `npm run backup` ونسخه خارج الخادم.
- [ ] `npx prisma migrate deploy`. **ممنوع** `migrate reset` و`migrate dev` على الإنتاج.
- [ ] تشغيل التطبيق والعامل.
- [ ] إنشاء أول مدير، وتفعيل مصادقته الثنائية فور الدخول.
- [ ] `npm run release:check` بلا فشل.
- [ ] `/api/health` سليم، ورؤوس CSP و HSTS موجودة.
- [ ] رابط حديث غير معتمد يعيد 404.
- [ ] تسجيل تلاوة حقيقية، وسماعها من حساب معلم.

## بعد النشر

- [ ] استعادة نسخة في بيئة مؤقتة خلال أسبوع.
- [ ] مراجعة المهام الفاشلة في اللوحة يومياً أول أسبوعين.
- [ ] قياس Lighthouse و Core Web Vitals على الخادم الحقيقي.

## التراجع

أعد الصورة السابقة. الترحيلات للأمام فقط، فإن كان الترحيل غير متوافق فأوقف الكتابة، واستعد النسخة في قاعدة جديدة، ووجه التطبيق إليها.
