# قائمة Go / No-Go للإطلاق

**القرار الحالي: NO-GO.** الموانع أدناه تحتاج مصادر خارجية أو قرارات بشرية، ولا يحلها الكود.

يوقع على القرار مالك الدار والمشرف العلمي والمسؤول التقني. البنود «آلي» يتحقق منها `npm run release:check` على بيئة الإنتاج.

## مطلوب قبل تفعيل الخدمة المعنية

| الخدمة | الشرط |
|---|---|
| المعلم الذكي | نجاح `npm run ai:eval` بمفتاح اختبار، ومراجعة النتائج بشرياً، وقرار قانوني |
| الإشعارات | مفاتيح VAPID للإنتاج، وتجربة Firefox و Safari |
| ألوان التجويد | قرار المشرف العلمي |
| مواقيت الصلاة | مقارنة بالجدول الرسمي لمدينة الدار |

## تحقق نهائي يوم الإطلاق

- [ ] `npm run quran:verify` ناجح على قاعدة الإنتاج.
- [ ] `npm run release:check` بلا فشل.
- [ ] `/api/health` سليم، والعامل يعمل.
- [ ] نسخة احتياطية مأخوذة قبل النشر، وخطة التراجع معروفة.
- [ ] صفحة حديث غير معتمد تعيد 404 على الدومين الحقيقي.
- [ ] تسجيل دخول حقيقي، وتسجيل تلاوة، واستماع المعلم.
